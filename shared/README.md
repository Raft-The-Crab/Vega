# Shared

This directory contains shared resources and assets used across all VEGA applications.

## Structure

- **assets/** - Shared assets including:
  - Branding (logos, icons, colors, typography)
  - UI resources (icons, cursors, patterns, overlays)
  - Templates (photo, design, social media)
  - Presets (brushes, gradients, patterns, adjustments, styles, effects)
  - Fonts
  - Plugin examples
  - Sounds and animations

- **fixtures/** - Test fixtures and sample data
  - Images (various sizes, formats, color spaces)
  - PSD files (compatibility testing)
  - VEGA projects (version testing)
  - Golden images (rendering reference)

## Asset Categories

### Branding
Logos, brand colors, typography, and visual identity assets.

### UI Resources
Icons, cursors, patterns, and UI overlays used across desktop and mobile.

### Templates
Pre-built project templates for common use cases.

### Presets
Brush presets, gradients, color palettes, adjustment presets, and more.

### Fonts
Font files and metadata for text rendering.

### Fixtures
Test data for development and automated testing.

## Usage

Assets in this directory are referenced by:
- Desktop application (Avalonia)
- Android application (Compose)
- Core rendering tests
- Documentation examples
